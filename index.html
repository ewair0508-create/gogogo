初次設定流程

依序完成下列 4 步,之後就只要在「藥品清單」分頁管理藥品即可。

1. 建立 Telegram Bot 並取得 Chat ID

  1. Telegram 搜尋 @BotFather,輸入 /newbot,照指示建立 bot。
  2. 記下 BotFather 給的 Bot Token(類似 123456789:ABC...)。
  3. 搜尋你剛建好的 bot 並對它傳一句話(例如「hi」)。這步不能省。
  4. 瀏覽器開啟下面網址(把 <TOKEN> 換成 Bot Token),從 JSON 找出 "chat":{"id": ...} 那個數字,就是 Chat ID:
    https://api.telegram.org/bot<TOKEN>/getUpdates

2. 設定 GitHub Secrets

  1. 到你的 repo → Settings → Secrets and variables → Actions。
  2. 按 New repository secret,新增兩筆:
    • TELEGRAM_BOT_TOKEN = 你的 Bot Token
    • TELEGRAM_CHAT_ID = 你的 Chat ID

3. 建立 GitHub Personal Access Token (PAT)

  1. 到 github.com/settings/personal-access-tokens。
  2. 按 Generate new token(選 fine-grained)。
  3. Repository access → Only select repositories,只選這個 repo。
  4. Permissions → Repository permissions → Contents 設為 Read and write。
  5. 產生 Token 後複製(只顯示一次),貼到「設定」分頁的 PAT 欄位。

4. (選用) 啟用 GitHub Pages

  1. repo → Settings → Pages → Source 選 Deploy from a branch → branch 選 main → folder /(root)。
  2. 等 1-2 分鐘後可以從 https://<你的帳號>.github.io/<repo>/ 開這個網頁,不用每次都本地開檔案。

運作原理

  • GitHub Actions 每 5 分鐘跑一次 scripts/reminder.mjs。
  • 腳本讀 medications.json,比對台北時間的當前時間。
  • 若某藥品的提醒時間在過去 5 分鐘內,透過 Telegram Bot 推送訊息。
  • 你在這個網頁編輯藥品 → 按「儲存到 GitHub」→ 透過 GitHub API 更新 JSON → 下次 cron 就會用新設定。

注意事項

  • cron 不保證準時,可能延遲 1-2 分鐘。建議提醒時間設為 5 分鐘倍數(08:00、08:05...),避免邊界問題。
  • repo 若是 public,medications.json 的藥品名稱會公開。建議把 repo 設成 private。
  • Free 帳號的 private repo 也可以跑 Actions,有月度免費額度,這種頻率(每 5 分鐘 ≈ 8,640 次/月,每次數秒)還在範圍內。
